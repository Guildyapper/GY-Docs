# Casual Preset

**Who it's for:** relaxed guilds where there are usually enough spots for everyone who clicks Can. No draft, no priority games.

## What It Sets

| Setting | Value |
|---|---|
| Fill mode | First come |
| Waitlist mode | Default |
| Fair mode | Off |
| Instant confirm | Off |

Other settings are not touched. Profiles with their own settings, limits and member priorities stay as they are.

## What Members See

- When they click **Can**, they are confirmed while there are spots. After that they go on the waitlist.
- There is no draft time and no rank message.
- When someone drops out, the next member on the waitlist moves up.

## Follow-ups

- If officers often lock spots by hand to keep early clickers out, a draft fits better. See [Draft Signups](/features/draft).
- Add [limits and platoons](/events/platoons) if you need a class balance.

## Set It Up Manually

You can skip the wizard. Open **Management → Server settings → Waitlist**, then **How signups fill (default)**.

1. Set **Fill mode** to **First come**.
2. Set **Waitlist mode** to **Default**.
3. Turn **Fair mode** off.

To set it for one profile only, open **Management → Signup Profiles**, open the profile's **Fill** line and choose **Own settings for this profile**.
