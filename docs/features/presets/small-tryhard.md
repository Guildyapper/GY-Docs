# Small Tryhard Preset

**Who it's for:** small, competitive rosters where every spot counts and officers want to review the result before it applies.

## What It Sets

| Setting | Value |
|---|---|
| Fill mode | Draft |
| Draft runs | Preview first (Premium), otherwise Automatic. 3 hours before node war |
| Instant confirm | Off |
| Show rank | Off |
| Waitlist mode | Custom priority |
| Fair mode | Off |

Other settings are not touched. Profiles with their own settings, limits and member priorities stay as they are.

## What Members See

- When they click **Can**, they are **Available**. No rank is shown.
- With Premium, officers get the projected roster before the draft time and can change it. At the draft time the roster is filled and the bot posts the result.
- Without Premium the draft runs automatically and there is no preview.

## Follow-ups

- **Add class group limits** (Management → Signup Profiles → Classes) so the draft keeps the class mix you need.
- Set member priorities so the order reflects who you want in.

::: info Premium
**Preview first** needs [Premium](/premium). Without it the preset applies **Automatic** and tells you so. See [Draft Signups](/features/draft) for how the preview works.
:::

## Set It Up Manually

You can skip the wizard. Open **Management → Server settings → Waitlist**, then **How signups fill (default)**.

1. Set **Fill mode** to **Draft** and **Draft time** to 3 hours.
2. Set **When the draft runs** to **Preview first** (Premium) or **Automatic**.
3. Turn **Instant confirm** and **Show rank** off.
4. Set **Waitlist mode** to **Custom priority** and turn **Fair mode** off.

To set it for one profile only, open **Management → Signup Profiles**, open the profile's **Fill** line and choose **Own settings for this profile**.
