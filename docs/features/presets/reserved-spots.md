# Reserved Spots Preset

**Who it's for:** competitive guilds with a core that should fill a fixed number of spots, while the other spots go by priority.

## What It Sets

| Setting | Value |
|---|---|
| Fill mode | Draft |
| Draft runs | Automatic, 3 hours before node war |
| Instant confirm | Personal priority at or above your core priority (suggested 5), stops at your reserved spots |
| Show rank | On |
| Waitlist mode | Custom priority |
| Fair mode | On |

Other settings are not touched. Profiles with their own settings, limits and member priorities stay as they are.

## What Members See

- Core members are **confirmed right away** until the reserved number of members are confirmed. Members an officer moved in count too.
- Everyone else, including core members after that, is **Available** and sees their place.
- At the draft time the remaining spots are filled by priority and the bot posts the result.

## Follow-ups

- **Set member priorities** for your core. The preset does not change any.
- Add [class group limits](/events/platoons) if you need a class balance.

## Set It Up Manually

You can skip the wizard. Open **Management → Server settings → Waitlist**, then **How signups fill (default)**.

1. Set **Fill mode** to **Draft**, **When the draft runs** to **Automatic** and **Draft time** to 3 hours.
2. Turn on **Instant confirm**, set the minimum priority, compare **Personal priority**, and stop at your number of reserved spots.
3. Turn **Show rank** on.
4. Set **Waitlist mode** to **Custom priority** and turn **Fair mode** on.

To set it for one profile only, open **Management → Signup Profiles**, open the profile's **Fill** line and choose **Own settings for this profile**.
