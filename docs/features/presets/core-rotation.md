# Core + Rotation Preset

**Who it's for:** guilds with a stable core that should always play, plus other members who rotate through the remaining spots.

## What It Sets

| Setting | Value |
|---|---|
| Fill mode | Draft |
| Draft runs | Automatic, 3 hours before node war |
| Instant confirm | Personal priority at or above your core priority (you choose it, suggested 5) |
| Show rank | On |
| Waitlist mode | Custom priority |
| Fair mode | On |

Other settings are not touched. Profiles with their own settings, limits and member priorities stay as they are.

## What Members See

- Core members (personal priority at or above the number you chose) are **confirmed right away** when they click Can.
- Everyone else is **Available** and sees their place, for example "You're **#31 of 50** (likely in)".
- At the draft time the remaining spots are filled by priority and the bot posts the result. The rest go on the waitlist.

## Follow-ups

- **Set member priorities.** The preset does not change any. Give your core members a personal priority at or above the threshold, or nobody is confirmed instantly.
- Add [class group limits](/events/platoons) if you need a class balance in the draft.

## Set It Up Manually

You can skip the wizard. Open **Management → Server settings → Waitlist**, then **How signups fill (default)**.

1. Set **Fill mode** to **Draft**, **When the draft runs** to **Automatic** and **Draft time** to 3 hours.
2. Turn on **Instant confirm**, set the minimum priority and compare **Personal priority**.
3. Turn **Show rank** on.
4. Set **Waitlist mode** to **Custom priority** and turn **Fair mode** on.

To set it for one profile only, open **Management → Signup Profiles**, open the profile's **Fill** line and choose **Own settings for this profile**.
