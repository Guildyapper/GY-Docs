# Officers Pick Preset

**Who it's for:** guilds where officers build the roster themselves and members only say whether they can play.

## What It Sets

| Setting | Value |
|---|---|
| Fill mode | Draft |
| Draft runs | Manual |
| Instant confirm | Off |
| Show rank | Off |
| Waitlist mode | Custom priority |
| Fair mode | Off |

Other settings are not touched. Profiles with their own settings, limits and member priorities stay as they are.

## What Members See

- When they click **Can**, they are **Available**. No rank is shown.
- Nothing happens at a set time. The roster stays empty until an officer fills it.
- Members see the result when an officer runs the draft or moves them in by hand.

## Follow-ups

- Officers: use **Run draft now** (officer menu of the signup, or the website) when you are ready, or move members by hand. Use pin in / pin out first if you want to force names. A signup with 0 spots does not draft: raise the spots first.
- Set member priorities so the draft has a sensible order.

## Set It Up Manually

You can skip the wizard. Open **Management → Server settings → Waitlist**, then **How signups fill (default)**.

1. Set **Fill mode** to **Draft** and **When the draft runs** to **Manual**.
2. Turn **Instant confirm**, **Show rank** and **Fair mode** off.
3. Set **Waitlist mode** to **Custom priority**.

To set it for one profile only, open **Management → Signup Profiles**, open the profile's **Fill** line and choose **Own settings for this profile**.
