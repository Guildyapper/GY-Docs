# Introduction

GuildYapper is a Discord bot and a [website](https://guildyapper.com) for Black Desert guilds. The bot handles day-to-day actions inside Discord: signups, profile updates, score uploads. The website gives officers and members bigger views for signups, roster work, scores, VOD reviews, and public statistics. Both work on the same data.

## What GuildYapper Helps With

| Area | What users see |
| --- | --- |
| Setup | Guided Discord setup with server type, region, roles, channels, Guild Tracker settings, and Trial Server automation. |
| Events | Node War, GvG, Guild League, draft, and custom signups with signup profiles, attendance states, and officer actions. |
| Platoons | Configurable platoons (in-game parties), platoon sizes, priority, waitlist rules, split platoons, and temporary event-only moves. |
| Roster | Member profiles, gear, class/spec, guild, function roles, platoon assignments, priorities, attendance history, and score snapshots. |
| Scores and VOD | BDO OCR screenshot uploads, Ikusa uploads, personal stats, alliance/guild breakdowns, and VOD reviews. |
| Tracking | Guild and player lookup, guild consistency, tierlists, class popularity, class performance, Guild Wars, and Arena of Solare. |
| Community | Yap messages, recruiting browser posts, merc signup posts, verification posts, and Trial Server flows. |
| Premium | Scheduler automation, VOD reviews, attendance safeguards, custom signup profiles, and bot profile customization. |

::: tip Commands Depend On Server Type
Discord only shows the commands available in your server type. The [Slash Commands](/reference/commands) page lists them by area so officers can quickly find the right one.
:::
