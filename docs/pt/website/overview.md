O site é o lado de painel maior do GuildYapper. O Discord é melhor para ações rápidas. O site é melhor quando você precisa de tabelas, filtros, gráficos, páginas de detalhes de pontuação ou edição de roster.

As páginas que mostram seu servidor, roster, perfil ou dados de gerenciamento requerem login pelo Discord. Páginas públicas como tierlists, Guild Tracker, estatísticas de classes, streams e guerras de guildas podem ser navegadas sem gerenciar um servidor.
:::

## O que os Oficiais Geralmente Usam

1. [Inscrições](https://guildyapper.com/management/signups) para gerenciar presença em eventos.
2. [Roster](https://guildyapper.com/management/roster) para revisar e editar dados de membros.
3. [Gerenciamento de Pontuações](https://guildyapper.com/management/scores) para fazer upload e corrigir sessões de pontuação de guerra.
4. [Painel do Guild Tracker](https://guildyapper.com/guild-tracker/dashboard) para acompanhar a atividade das guildas rastreadas.
5. [Desempenho de Classes](https://guildyapper.com/class-performance) para comparar resultados de classes entre fontes de dados.

## O que os Membros Geralmente Usam

1. [Perfil](https://guildyapper.com/profile) para manter suas próprias informações atualizadas.
2. [Pontuações Pessoais](https://guildyapper.com/scores) para revisar uploads, favoritos e estatísticas.
3. [Inscrições](https://guildyapper.com/management/signups) quando os oficiais querem que os membros inspecionem os detalhes do evento no site.

::: tip Discord e Site Ficam Conectados
As inscrições criadas no Discord aparecem no site. Edições de presença e grupos no site podem atualizar os mesmos dados de inscrição usados pelo bot.
:::

## Problemas Comuns

### Não consigo ver meu servidor

Certifique-se de estar logado com a conta do Discord que está no servidor e tem o cargo de membro configurado.

### Consigo visualizar mas não editar

A edição requer privilégios de oficial/admin para aquele servidor GuildYapper.

### Meus dados de membro estão desatualizados

Atualize seu perfil no site ou use:

```text
/member update
```
