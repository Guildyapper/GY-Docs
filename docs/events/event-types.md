# Event Types And Signup Profiles

A signup profile is a layout: it decides which platoons (in-game parties) and which function roles are available on an event. The default platoon is always available. One profile is the default for new Node War signups when no profile is chosen.

## Who Can Use It

Officers/admins configure signup profiles. Members simply see the resulting layout on their signups.

## System Profiles

GuildYapper ships with five system profiles.

| Profile | Use it for |
| --- | --- |
| Nodewar (Occupation) | Occupation node wars. Default profile out of the box. |
| Nodewar (Construction) | Construction node wars. |
| Siege | Siege wars. |
| Blue Battlefield | Blue Battlefield events. |
| War of the Roses | War of the Roses events. |

## Custom Profiles

You can create custom profiles beyond the five system profiles. On the free plan, a server has five profiles and five function roles. Premium unlocks custom profiles and unlimited function roles.

## Configuring Profiles

Configure profiles in Discord:

```text
/configure profiles
```

Or on the website, open the **Signup Profiles** page and use the **Profiles** tab.

Each profile has a name, a description, available platoons, available function roles, an activation switch, and the option to set it as the default.

::: info Activation Does Not Affect Existing Signups
Activating or deactivating a profile only changes what is offered for new signups. It does not affect signups that already exist.
:::
